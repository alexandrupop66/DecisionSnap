What the app does

DecisionSnap turns a comparison into visible criteria, option scores, human-controlled weights, and a deterministic ranking. Gemini may structure the criteria and scores, but it does not choose the winner. The browser calculates the final ranking from the numbers shown on screen.

One real action through the system

Visible result: public/js/scoring.js → calculateRanking() applies the weights locally, while rebalanceWeights() keeps the total at 100%. The winner, explanation and transparent breakdown are then rendered on the same page.

To change this, start here

  • Change demo values or the demo question: public/js/demo-data.js.
  • Change how weights behave or ranking is calculated: public/js/scoring.js.
  • Change the Gemini instructions or schema: src/ai.js → buildGeminiRequest().
  • Change criteria/options composer behaviour: public/js/app.js → renderComposer() and related composer helpers.
  • Change layout or visual treatment: public/index.html and public/styles.css.

A practice to reuse

The useful AI pattern in this project is prompt as contract, not prompt as authority. Instead of asking Gemini “Which laptop is best?”, DecisionSnap gives it a narrow role, exact inputs, a 0–100 desirability convention, a strict JSON shape, and a prohibition on ranking or weighting. The tests in test/ai.test.js then verify that the structured output can be safely consumed.

This same pattern can be reused in other projects: let AI handle an ambiguous language task, constrain its output into a machine-checkable shape, validate it, and keep any critical calculation or policy decision in deterministic code when practical.

Run it again

  1. From the project folder, run npm start.
  2. Open http://localhost:3000.
  3. For live AI, configure GEMINI_API_KEY using 1_SETUP_GEMINI_KEY.bat on Windows.
  4. Run npm test to execute the project checks.

Why the architecture stayed small

The proof of concept uses Node built-ins and plain browser JavaScript, with no database, authentication, framework, bundler, or runtime npm dependencies. That keeps the demo path easy to run and leaves the product’s distinctive idea—the transparent decision logic—visible rather than buried under infrastructure.
